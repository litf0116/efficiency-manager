## 5. 未发天数 (未发天数.csv)

### 描述
记录各小组的延迟发货天数异常数据。

### 字段说明
| 字段名 | 类型 | 说明 |
|--------|------|------|
| team | VARCHAR | 小组名称 |
| day_1~day_8 | FLOAT | 各统计日的天数偏移值 |

### 数据说明
- 天数字段为imestamp偏移值，需减去基准日期(约45893天)得到实际天数
- 例如: 45893.0 - 45893 = 0天延迟

## 数据库设计建议

### 核心表结构

```sql
-- 仓库表
CREATE TABLE warehouse (
    id INT PRIMARY KEY,
    name VARCHAR(50),  -- 海宁仓/临平仓
    location VARCHAR(100)
);

-- 小组表
CREATE TABLE team (
    id INT PRIMARY KEY,
    warehouse_id INT,
    name VARCHAR(100),
    floor VARCHAR(20),
    function VARCHAR(50),  -- 收货/仓储/质检
    FOREIGN KEY (warehouse_id) REFERENCES warehouse(id)
);

-- 人效记录表
CREATE TABLE efficiency_log (
    id INT PRIMARY KEY,
    team_id INT,
    year INT,
    month INT,
    efficiency FLOAT,  -- 人效值
    created_at TIMESTAMP
);

-- 客户表
CREATE TABLE customer (
    id INT PRIMARY KEY,
    warehouse_id INT,
    name VARCHAR(100),
    category VARCHAR(20),  -- A类/B+类/B类/C类
    monthly_amount DECIMAL(15,2)
);

-- 场地租金表
CREATE TABLE space_rent (
    id INT PRIMARY KEY,
    building VARCHAR(50),
    floor VARCHAR(20),
    area_sqm DECIMAL(10,2),
    monthly_rent DECIMAL(15,2),
    tenant VARCHAR(100)
);

-- 标准人效表
CREATE TABLE std_efficiency (
    id INT PRIMARY KEY,
    operation VARCHAR(100),
    unit VARCHAR(20),
    std_rate_per_day DECIMAL(10,2)
);
```
