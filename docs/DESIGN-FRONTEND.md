## 一、设计原则

### 1.1 核心目标

- **微信小程序**: 组长快速上报，无需登录，选择小组即可使用
- **Web 管理后台**: 数据可视化，管理功能完整

### 1.2 设计价值观

| 维度 | 微信小程序 | Web 管理后台 |
|---|---|---|
| 优先级 | 输入效率 > 视觉 | 数据密度 > 装饰 |
| 交互 | 单手操作，步骤少 | 鼠标 + 键盘，支持批量 |
| 信息层级 | 简单直接 | 丰富但有主次 |
| 视觉风格 | 轻量清晰，符合微信规范 | 专业数据导向 |
| 登录方式 | 无需登录，选择小组即可 | 用户名密码登录 |

### 7.3 微信小程序特殊说明

**为什么选择 Taro:**
- 使用 Vue 3 开发，代码复用性高
- 可编译为微信小程序、H5等多端
- 支持微信小程序云开发
- 社区活跃，文档完善

**微信登录:**
- 无需个人微信授权登录
- 小组选择后，记录到本地存储
- 下次打开自动识别小组

**数据存储:**
- 小组选择信息存储在 `wx.setStorageSync`
- 无需后端登录认证

## 八、页面流程

### 8.1 H5 上报流程

```
登录 → 首页 → 选择周次 → 填写出勤 → 填写各模块数量 → 实时人效 → 提交 → 成功
```

**关键节点:**
1. 自动带出小组信息和周次
2. 每填一个数字，实时计算人效
3. 人效低于阈值时，显示预警
4. 提交后显示汇总确认
5. 成功后可查看历史

### 8.2 Web 后台审核流程

```
登录 → 仪表盘 → 查看汇总 → 明细钻取 → 数据审核 → 月度汇总
```
